Conexão com o NST

Origem dos parâmetros

Ligado = usar webhook (true). Desligado = usar configuração local/NST (false).
Proxy

Ligado: usa o proxy recebido. Se vier vazio, usa residencial NST.
Desligado: sempre usa residencial NST, ignorando o webhook.

User-Agent

Ligado: preserva o UA recebido, inclusive JSON com prefixo !.
Desligado: o NST gera o fingerprint e o UA padrão de um novo perfil desktop.

URL inicial

Ligado: abre a URL do webhook. Desligado: abre a URL fixa abaixo.

Tipo da operação

Ligado: usa normal/retentativa do webhook. Desligado: usa o tipo fixo abaixo.

O nome é sempre exatamente number, enviado como texto. Em retentativas, proxy e User-Agent originais são preservados, independentemente dos seletores.

Padrões locais e proxy residencial

Proxy integrado exige NST 1.19.0+ e créditos. Uma operação normal exclui o perfil anterior e seus dados. User-Agent móvel não reproduz um Android/iPhone real nem altera a versão do motor NST.

Webhook do processo

Envie um POST JSON para:






Cabeçalho obrigatório: Authorization: Bearer SEU_TOKEN_DO_WEBHOOK


{
  "number": "5511999999999",
  "tipo": "normal",
  "proxy": "http://user:pass@proxy:porta",
  "url": "https://seu-site.com",
  "platform": "macOS",
  "platformVersion": "15.0.0",
  "kernelMilestone": "140",
  "fingerprint": {
    "userAgent": "Mozilla/5.0 ...",
    "deviceMemory": 8, "hardwareConcurrency": 8,
    "flags": { "canvas": "Noise", "webgl": "Noise", "localization": "Custom",
               "timezone": "BasedOnIp", "webrtc": "Masked", "geolocation": "Custom" },
    "localization": { "locale": "pt-BR", "languages": ["pt-BR","pt"], "basedOnProxy": true },
    "screen": { "width": 393, "height": 873 },
    "geolocation": { "latitude": "-22.80", "longitude": "-43.37", "accuracy": "100" }
  }
}
fingerprint, platform/platformVersion, kernelMilestone, groupName e note são opcionais e passam direto ao NST. Sem fingerprint, user_agent solto continua obrigatório. Valores inválidos são rejeitados com o nome da chave.
O retorno confirma a criação/abertura, não o carregamento completo do site. Retentativa abre uma nova aba, preservando a sessão. Evite repetir chamadas normal após falhas; confira a etapa retornada antes de reenviar. Para fechar apenas o navegador (perfil preservado): {"number":"...","tipo":"fechar"}.


Este endereço funciona apenas neste computador. Para receber de serviços externos será necessário publicar o webhook por HTTPS sem expor /config nem /api/config. Não compartilhe o token.
